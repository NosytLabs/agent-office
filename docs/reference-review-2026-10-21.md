## Product references

[Termi](https://termiprotocol.com/) describes a real terminal, task boards, memory, and checkpoints. Its [changelog](https://termiprotocol.com/changelog) describes refreshing newly installed CLI discovery, quote-safe input, focus stability, bounded transcript work, and lower idle rendering. [BridgeMind](https://www.bridgemind.ai/) describes a workspace with running-agent visibility and retained task context. These are publisher claims, not locally verified installed behavior or reusable source licenses.

The selected improvements are independently written: fresh OpenCode tasks, explicit executable rediscovery, literal run search plus process-status filters, plain-text run snapshots, and original coffee/server sprite loops. Existing saved briefs, attention navigation, accounting, and room controls remain their shared surfaces. Opening a panel, downloading output, refreshing discovery, and interacting with furniture never start a process.

## Runtime contract and limits

The installed CLI reported `opencode v2.0.29`; `opencode run --help` exposes `--standalone`, `--format`, `--auto`, session continuation, and remote-server flags. This adapter selects only `run --standalone`, passes literal prompt bytes on stdin, and uses the allowlisted project as cwd. It inherits the CLI's configured account and permissions. New noninteractive permission requests are rejected; no automatic approvals are enabled. Context7's source evidence documents piped input and noninteractive permission handling in [OpenCode run](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/cli/cmd/run.ts) and the [V2 runner](https://github.com/anomalyco/opencode/blob/dev/packages/cli/src/run/noninteractive.ts).

Help output confirms the installed command interface. Executable fixtures establish this office's admission, argv/stdin, cancellation, output, and rediscovery behavior. Neither proves an authenticated model completed a provider-backed task. OpenCode V2.0.29+ and Claude Code 2.1.259+ are documented requirements; executable discovery alone does not verify versions or authentication.

Existing-session handoff, durable delivery reconciliation, interactive PTYs, remote permission responses, scheduling, and autonomous orchestration remain separate unfinished capabilities in [issue #18](https://github.com/NosytLabs/agent-office/issues/18). Downloaded run snapshots preserve readable evidence, not durable server-side retry receipts.
