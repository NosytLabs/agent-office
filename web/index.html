HOW IT WORKS

Every live agent session is a pixel character. Hermes CLI, Telegram, cron, and OpenCode all write the same event log. This page just folds that log into a floor plan.

agents → hooks → ~/.hermes/pixel-office/events.jsonl → /state → canvas

Hermes plugin observes tool/session hooks. OpenCode plugin maps tool.execute.* and session events onto the same JSONL. VS Code polls /state — the webview never talks to the agents.

XP and unlocks persist in progress.json. Cosmetics (beanie, visor, gold monitor, cape) unlock by rank and by runtime: Hermes caduceus, OpenCode >_, Telegram plane, CLI prompt.

Unlike Pixel Agents (Claude Code only), this floor is runtime-agnostic. Visual only — nothing blocks, vetoes, or edits prompts.

Buttons: roster lists every agent, stats shows XP buckets, unlocks is the catalog, all cycles a platform filter.
