# Sprite Assets

Character and pet walk sheets adapted from [pixel-agents](https://github.com/pixel-agents-hq/pixel-agents) by Pablo De Lucca — MIT License.

- Character sheets (`characters/char_0..5.png`): 112×96 PNG, 3 direction rows (down/up/right) × 7 frames of 16×32. Col 0 = idle, cols 1–6 = walk. No left row — mirror right.
- Pet sheets (`pets/claudio.png`, `pets/gitcat.png`): 96×96 = 6 cols × 3 rows of 16×32. Col 0 = idle, cols 1–5 = walk.
- Sleeping cat (`pets/sleep_cat.png`): 24×16 isolated pixel sprite.
- Furniture (pixel-art, magenta-keyed): DOOR 32×48, COFFEE 32×32, LARGE_PLANT 32×48, CACTUS 16×32, BIN 16×24, PACKAGE 16×16, WATER_COOLER 16×32, LAMP 24×24, CLOCK 16×16, BOOKSHELF 32×48, FISH_TANK 32×24, PARTITION 48×24.
- NPCs (`npcs/mail.png`, `npcs/cleaner.png`, `npcs/intern.png`): 32×48 isolated idle sprites, distinct from agent sheets.
