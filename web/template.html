This office reflects events from your coding agents. It does not run tasks or approve actions. Pets and room objects are decoration.

Connect a runtime

Run python3 install.py from the repository, restart your runtime, and keep python3 run.py open. The installer detects Hermes, OpenCode, Claude Code and VS Code.

The demo runs in a temporary directory and is marked DEMO. Its XP and events are separate from your real sessions.
