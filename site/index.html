Full installation guide ↗
⌂

The server binds to 127.0.0.1. The office serves local assets and makes no analytics or model-provider requests.

Make yourself at home

Start the office

In a terminal, clone the repo and start the server:

git clone https://github.com/NosytLabs/agent-office.git
cd agent-office
python3 run.py

Then open http://127.0.0.1:8113. Keep this terminal running.

Connect existing runtimes

From the same checkout, in a second terminal:

python3 install.py

The installer adds observer definitions for detected tools and preserves unrelated configuration. Restart connected runtimes after installation. It does not install those runtimes.

For Codex, review and trust the hook through /hooks. Existing OpenCode JSONC receives manual setup instructions.

Open the editor view

The installer can add the included VS Code extension. Keep the local server running, reload VS Code, and run this command from the Command Palette: 

Agent Office: Open Floor

For remote workspaces or a different local port, follow the extension connection guide.

Before you move in

A few useful answers.

Does Agent Office control my agents?＋

No. It observes the sessions you connect. Start work, send prompts, answer questions, and grant permissions in the original runtime. The office shows you where attention is needed.

Is the demo connected to real agents?＋

The public demo uses fictional sessions, activity, XP, and usage. Its preferences stay in your browser. To observe actual work, run the local server and install the adapters on the same computer as your runtimes.

How accurate are the usage and cost numbers?＋

The office records the counters a supported source reports, with replay protection and corrections. It keeps unavailable values distinct from zero and labels partial coverage. Cost values are runtime estimates when supplied, not provider invoices. Read each adapter’s scope.

Will the activity log keep growing?＋

Retained raw history defaults to the newest 1,000 events within seven days and 5 MiB. Change all three limits in Customize. History pruning preserves earned progress, usage totals, and unanswered approvals. Usage identities remain separately for corrections, so this is not a hard cap on the entire database.

What is free, and what can I customize?＋

The repository’s code is MIT licensed. Run it locally and customize the themes, names, characters, furniture, aquarium, and music. Runtimes and model providers have their own requirements and pricing. Optional commercial Smallburg art is not bundled; the public app includes original fish sprites.

What is still being built?＋

More runtime adapters, source task-list snapshots, current-context gauges, and broader host integration checks are still open work. The existing Tasks panel shows observed session activity. The audit record separates verified behavior from remaining work.
