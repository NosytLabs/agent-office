Website and screenshots

The website uses original layout and copy, with screenshots captured from the actual Agent Office application using synthetic test sessions. The screenshots do not represent a live connected account. The public app’s original generated furniture, robot, and fish are documented in the sprite provenance record.

The screenshots also show character and pet art retained from Pixel Agents with the upstream MIT notice. Optional commercial Smallburg packs are not included in this website or the public demo. Their local use requires a legitimate license.

Fonts, icons, and runtime marks

References and independent implementations

Pixel Agents, Hootbu’s Pixel Agents, and other related projects informed the feature research. The source review records inspected code, adopted ideas, license boundaries, and features left for future work.

Handy and The Pixel Office were visual references for a clear product introduction and useful feature tour. Their copy, artwork, and source code were not copied into this site.
